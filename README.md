# Office scan viewer

A walkable 3D scan, viewed in the browser: https://srahman16.github.io/scan-b10ee46aab/

Keys: W A S D to walk, mouse to look, F for the nearest real photo, G for picture controls.
The scan is stored in pieces under `data/` (listed in `office.parts.json`) because GitHub does not accept single files over 100 MB.
